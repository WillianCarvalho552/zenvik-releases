# Zenvik PDV — pacotes de atualização

Este repositório guarda apenas os **pacotes de atualização** do Zenvik PDV, publicados em *Releases*.

- As lojas recebem as atualizações automaticamente pelo painel do Zenvik.
- Cada pacote só é instalado se conferir com a **assinatura digital do fornecedor** e com o **SHA-256** informado no manifesto assinado. Pacotes alterados são recusados.
- O uso do Zenvik exige licença ativa da Zenvik Tecnologia.
